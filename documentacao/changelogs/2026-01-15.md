# Changelog - 2026-01-15

## Refatoração da Arquitetura WebCiclo

### 🎯 Objetivo

Reorganizar a estrutura de arquivos do projeto WebCiclo para seguir o padrão arquitetural definido em `regrastaxi.md`, melhorando a organização, manutenibilidade e clareza do código.

---

### ✅ Mudanças Implementadas

#### 1. Criação da Nova Estrutura de Diretórios

**Backend:**

- `backend/app/` - Aplicação principal
  - `main.py` - Ponto de entrada (ex-`app.py`)
  - `config.py` - Configurações
  - `schemas.py` - Validação de formulários (ex-`forms.py`)
  - `src/models/` - Repositórios e modelos de dados
  - `src/services/` - Lógica de negócio
  - `src/scripts/` - Scripts utilitários
- `backend/logs/` - Logs de execução

**Frontend:**

- `web/templates/` - Templates HTML
- `web/static/css/` - Estilos CSS
- `web/static/js/` - Scripts JavaScript
- `web/static/images/` - Imagens

**Documentação:**

- `documentacao/refs/csv/` - Dados CSV de referência
- `documentacao/refs/pdf/` - PDFs de referência

#### 2. Migração de Arquivos

**Backend:**

- `app.py` → `backend/app/main.py` ✅
- `config.py` → `backend/app/config.py` ✅
- `forms.py` → `backend/app/schemas.py` ✅
- `repositories/*` → `backend/app/src/models/` ✅
- `services/*` → `backend/app/src/services/` ✅
- `scripts/*` → `backend/app/src/scripts/` ✅

**Frontend:**

- `templates/*` → `web/templates/` ✅
- `static/css/*` → `web/static/css/` ✅
- `static/js/*` → `web/static/js/` ✅
- `static/images/*` → `web/static/images/` ✅

**Dados:**

- `CSV/*` → `documentacao/refs/csv/` ✅
- `PDF/*` → `documentacao/refs/pdf/` ✅

#### 3. Atualização de Imports

Todos os imports Python foram atualizados para refletir a nova estrutura:

**`backend/app/main.py`:**

```python
from backend.app.config import Config
from backend.app.src.services.course_service import CourseService
from backend.app.schemas import LoginForm
```

**`backend/app/src/services/*.py`:**

```python
from backend.app.src.models.course_repository import CourseRepository
from backend.app.src.services.validation_service import CourseValidator
```

**Configuração de templates:**

```python
app.template_folder = "../../web/templates"
app.static_folder = "../../web/static"
```

- ❌ Deletado: `flask_app.py` (duplicado)

- ❌ Removidos diretórios vazios: `repositories/`, `services/`, `scripts/`, `templates/`, `static/`, `CSV/`, `PDF/`
